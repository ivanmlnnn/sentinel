# Security Policy

IVTECH Sentinel is an early-stage security research MVP. The current hosted version is read-only and does not sign or broadcast transactions.

## Reporting

Please do not publish exploitable details or private wallet information in public issues. Contact the project maintainer privately through the official IVTECH project contact channel before public disclosure.

Include:
- A concise description and impact.
- Reproduction steps.
- Affected endpoint or component.
- Sanitized logs or transaction references.
- Suggested mitigation, if known.

Never include seed phrases, private keys, access tokens, or other secrets in a report.

## Scope

In scope: application input validation, API authorization, risk-decision integrity, threat registry integrity, AI prompt-injection behavior, and wallet integration.

Out of scope for the current release: claims about the security of NEAR itself, wallet providers, or third-party RPC infrastructure.
